**MyShop** is a complete, multi-page frontend e-commerce web application. It delivers a full online retail customer journey—from browsing curated product categories to cart management, wishlists, and user authentication flows.

## ✨ Features & Pages

- **🏠 Home & Product Discovery (`home.html`, `index.html`):** Hero promotions, category grids, featured product carousels, and seasonal deal banners.
- **🛒 Shopping Cart (`cart.html`):** Item quantity controls, subtotal/tax calculation, and checkout transitions.
- **❤️ Wishlist (`wishlist.html`):** Bookmark favorite products for future purchases.
- **🔐 User Authentication (`login.html`, `signup.html`, `forgot.html`, `reset.html`):** Full authentication view suite with input validation and password recovery.
- **ℹ️ Informational Pages (`about.html`, `contact.html`):** Company mission, brand values, FAQ, and interactive customer inquiry form.
- **📱 Fully Responsive:** Adaptive layouts optimized for mobile, tablet, and desktop viewports.

---

## 🛠️ Tech Stack

- **Markup:** HTML5 semantic structure
- **Styling:** CSS3 custom styles, flexbox, and grid layouts
- **Interactivity:** Vanilla JavaScript (ES6+) for DOM manipulation and state
- **Hosting:** GitHub Pages
